# dirstats-gui

The graphical front end (egui) of [dirstats](https://github.com/iikachu/dirstats), a disk usage viewer
with treemaps. It is published because the `dirstats` crate depends on it,
not for use on its own. Install the app with `cargo install dirstats`.
