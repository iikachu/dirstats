# dirstats-treemap

Treemap layouts (squarified and rows) and cushion rendering for trees built
by [`dirstats-scan`](https://crates.io/crates/dirstats-scan). It draws into
an RGBA buffer, shades in OKLCH, and finds the node under a pixel.

Part of [dirstats](https://github.com/iikachu/dirstats), a disk usage viewer with treemaps. The layout and
cushion shading are ported from WinDirStat.
